# LittleTree — Team Project Development Log

UE5 기반 팀 프로젝트에서 **주차별 작업, 기획 의사결정, 협업 과정**을 기록한 저장소입니다.

이 저장소는 팀 전체 결과물을 대신하기보다, 프로젝트 안에서 내가 어떤 문제를 다루고 어떤 방식으로 결정 과정에 기여했는지를 남기는 것을 목적으로 합니다.

---

## What This Log Shows

- 회의 안건과 논의 사항을 구조화한 과정
- 스토리와 실제 플레이 흐름을 연결하기 위한 기획 조정
- 마을 / 필드 / 던전 진행 구조 구체화
- 던전 테마·기믹 후보 비교와 결정 과정
- 결정 사항을 문서화하고 다음 작업으로 연결한 기록

---

## Contribution Evidence

공개된 주차 기록에서 확인 가능한 기여 내용은 다음과 같습니다.

- 스토리 기획 논의를 위한 팀 구성 및 안건 정리
- Notion 기반 문서와 기획 템플릿 정리
- 회의 진행 및 의견 수집
- 여러 제안을 비교하고 충돌 지점을 조정
- 마을 / 필드 진행 방향과 던전 기획을 문서화

> 역할 명칭보다 **실제로 수행한 작업과 산출물**을 우선 기록합니다. 이후 코드 구현 기여가 추가되면 같은 방식으로 담당 기능, 관련 Source, 디버깅 근거를 연결합니다.

## Recommended Weekly Format

각 주차 기록은 아래 순서를 권장합니다.

```text
이번 주 목표
→ 내가 맡은 역할
→ 문제 / 논의 배경
→ 선택지와 판단 기준
→ 내가 한 작업
→ 결과 / 산출물
→ 다음 주 연결점
```

팀 전체가 한 일과 **내가 직접 한 일**을 분리해 작성하면 면접에서 기여 범위를 빠르게 확인할 수 있습니다.
